## Cross-check vs current dataset (`slayer-data.json`, 42 tasks)

Every one of the 42 dataset tasks that lists `"duradel"` in `assignedBy` IS present in Duradel's table above.

  "Chance of Heavy Frost" unlock). Quantity 70-120 (extended 180-240). NOT present in `slayer-data.json`.

  DS1 is explicitly NOT required for the Frost dragons task. Variant data captured in `variants-dragons.md`.
